# AzureSOC-Agent

Natural language operations for:

- Microsoft Sentinel
- Log Analytics
- KQL
- Azure Data Explorer
- Defender XDR
- Entra ID

## Install

pip install -r requirements.txt

## Run

python src/azuresoc_agent/cli/main.py
